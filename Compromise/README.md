# Compromise


## Bundled JavaScript (2026-09-20)

Bundles Compromise 10.7.2, the newest 10.x release, preserving the values().data() and verbs().data() APIs. Compromise 14.17.0 contains class syntax rejected by the current OpenAF Rhino runtime and changes these APIs. Load compromise.js to use the bundled library offline. The optional update=true maintenance action needs network access and is pinned to 10.7.2.

The release versions, archive URLs and npm integrity checksums are recorded in upstream.json. Upstream license notices are retained. Maintenance downloads are not required at runtime.
