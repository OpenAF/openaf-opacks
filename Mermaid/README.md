# Mermaid


## Bundled JavaScript (2026-09-20)

Mermaid 12.0.0 uses the upstream all-in-one minified browser bundle. No ESM chunks are needed. Load mermaid.js before generating OpenAF Markdown HTML. Diagrams that explicitly reference remote images or icon services still need those resources supplied locally.

The release versions, archive URLs and npm integrity checksums are recorded in upstream.json. Upstream license notices are retained. Maintenance downloads are not required at runtime.
