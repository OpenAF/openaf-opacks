# asciinema


## Bundled JavaScript (2026-09-20)

Bundles asciinema-player 3.17.0 as the all-in-one minified browser build, including its embedded WebAssembly payload, plus matching CSS. No separate worker or WASM download is needed. Serve recordings locally for offline use. The OpenAF embedding helper is preserved.

The release versions, archive URLs and npm integrity checksums are recorded in upstream.json. Upstream license notices are retained. Maintenance downloads are not required at runtime.
